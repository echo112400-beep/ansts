# Console 管理面交互原型

依据：[Console 管理面功能设计](./console-management-design.md)。

## 访问

- 现有本机静态服务：[打开管理原型](http://127.0.0.1:8088/ansts_console_management.html)。
- 无服务时，可用现代浏览器直接打开 [HTML 入口](./ansts_console_management.html)。移动或分发时同时保留同目录的 `console-management/prototype.css` 和 `console-management/prototype.js`。
- 原参考页、SRE 原型及生产接口保持原有入口；本原型不发送管理 API 请求。

使用已确认的浅色中性灰、桌面优先工作区。总览突出具体待办，顶部持续展示作用域与演示标识；窄屏先展示需要处理的对象。按钮、对话框与首次内容进入有短促反馈，支持减少动态效果偏好。

## 建议演示步骤

### 1. 租户与任务准入

1. 默认使用陈（SRE_ADMIN），进入“租户与配额”，创建新的租户，设置允许区域和额度。
2. 进入“任务”，选择新租户提交任务；回到租户详情核对任务、Sandbox、CPU 和内存承诺。
3. 在顶部“原型演示控制”切换额度耗尽、平台容量不足或费用未知场景，观察不同阻断原因。容量不足进入有限时等待，可重新检查或推进至超时。
4. 编辑额度时先提交管理操作；跨区域变更需切换另一位管理员审批。额度低于当前占用时保留已有任务，新增受阻。

### 2. 资源纳管与维护

1. 可用 `body-apn-02` 演示待验证 → 待启用 → 服务中，或登记新的已供应资源。
2. 进入 `body-usw-07`，查看关联任务及 Gateway，再准备维护。
3. 提交后先停止新分配；推进执行会在候选容量满足时迁移模拟任务与 Sandbox，进入恢复验证。
4. 连续推进五分钟观测后才完成恢复验证；可模拟再次超标重置窗口。最后回到资源详情确认下线。
5. 批量维护可选择 `body-usw-07` 与 `gw-usw-01`，切换部分失败场景，观察不同目标状态和未完成项重试。

### 3. 任务取消和重执行

1. 进入 `task-83af`，取消预览列出运行子任务及已完成子任务；先受理取消，再确认停止，最后独立确认资源释放。
2. 可模拟子任务在取消期间自然完成，最终仍保留真实完成状态；停止未确认场景会产生人工待办且保留额度。
3. 对 `task-83b8` 人工重运行或从历史回合分叉，得到新任务标识及来源关系。缺少历史数据时阻止分叉。
4. 对有已知外部写入的任务重新运行，会进入单独的管理审批，执行前再次检查当前准入条件。

### 4. 配置审批、发布与恢复

1. 首页的 `OP-0241` 由周发起，陈可以审批；填写审批意见后再单独执行。
2. 分别推进两个区域，检查实际版本；下发响应取得后仍需实际状态验证。
3. 可在批次间暂停、恢复，或用部分失败场景演示保留已生效版本及定向重试。
4. 发布完成后“创建恢复变更”生成新的草稿与版本，不立即改变实际配置。
5. 也可从“策略与发布”创建草稿、保存后刷新找回，再模拟其他人更新基础版本，验证旧草稿被阻止。

## 演示控制、身份与状态

默认全平台管理员陈；周是另一位全平台管理员。林为 OPERATOR，许为 VIEWER，两者限定在 US West / Northstar。切换身份重新应用范围并清除已展开的敏感原文；发起者不能审批自身请求。

可切换正常、数据过期、接口不可用、容量不足、额度耗尽、费用未知、部分失败、停止未确认、版本冲突、历史回合缺失和恢复再次超标等场景。切换不覆盖原操作快照；操作中断后可在记录中继续跟踪。故障注入控制与产品真实状态分开呈现。

任务、资源、租户、操作、审计及已保存草稿在当前浏览器本地持久化，不跨设备同步。分享链接只携带页面、对象和筛选，不携带身份授权。顶部可重置本原型模拟数据；浏览器存储失败时保留会话状态并提示导出。

## 能力限制

这是用于评审功能和操作行为的前端原型。所有额度一致性、任务取消确认、资源迁移、版本发布、计费、权限检查和审计证据都在本地模拟；它们不证明已有后端实现了相应生产能力。

身份选择不是真实登录，本地审计不是生产防篡改存储，费用不是账单。生产接入仍需功能设计第 13 节中的身份、逐资源授权、持久化、一致性及接口契约。

Brain 维护在没有控制承接节点时阻止；Host 维护要求承载职责先处理；资源失联或容量不足不伪造下线成功。专家工具保留能力说明，不提供伪造生产执行结果的按钮。
