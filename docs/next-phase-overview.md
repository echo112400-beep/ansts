## A 当前差距

| 目标 | 当前限制 |
| --- | --- |
| 故障恢复 | 不确定任务缺少核对入口 |
| 安全执行 | 内部接口缺身份校验 |
| 高可用 | Gateway 状态独立，Brain 入口固定 |
| 任务执行 | 执行主要写 trace，部分控制台 API 未接入 |

## B 下一轮优先交付

| 顺序 | 特性 | 验收条件 |
| --- | --- | --- |
| N1 | 执行尝试与核对 | 崩溃后状态明确，禁止盲目重放 |
| N2 | 身份与租户隔离 | 伪造、越权和绕过准入请求被拒绝 |
| N3 | 可终止执行器 | 失租后停止进程，结果可靠回报 |
| N4 | 容器故障矩阵 | 重启、断网、旧 fence 场景可复现 |
