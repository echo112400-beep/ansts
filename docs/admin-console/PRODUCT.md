# 8088 后台管理

按 docs/index.html 的12个管理域建立真实管理入口，沿用 ui/hrui v2 的纸白、四阶文字、蓝色强调、Inter/JetBrains Mono、分组侧栏和表格/抽屉。现有登录、Profile、任务创建/日志/产物/取消及系统拓扑保持可用。

模块：平台态势、队列健康、节点/Cell、租户配额/FinOps、任务诊断、审批核对、配置治理、运行面、观测、Agent协同、联邦/灾备、安全/RBAC。管理域使用当前身份可访问的数据，搜索、筛选、刷新和检查任务有效；SRE 可执行现有带版本与证据的核对决定。

没有运行后端的功能不得用 docs 原型默认数值冒充：配额执行准入、计费、通用审批流、配置版本发布/回滚、LayerFS 分支管理、SLO/自愈、算力市场、跨地域迁移/纠删码证明、账号授权编辑都明确标为未接入。安全显示真实会话和权限，不以演示默认 TEE/SPIFFE/eBPF/发布门控宣称生产合规。

验收：所有导航有可用页面，管理聚合遵守租户隔离，Viewer不能写，SRE核对需要证据/CAS/确认；无伪造数据和假成功。桌面/手机无溢出，错误保留快照，现有浏览器回归通过，生产构建与部署完成。范围与未接入项随实现记录。

后续高级能力的设计与实现任务见 [后台能力建设方案](../admin-platform-plan/README.md)：首期聚焦内部成本分摊与容量分配，多地域先做供应商无关规划。该文档为待实施方案，不改变上述未接入状态。
