# RG-06：真实地域接入与恢复演练门禁

状态：待配置、未验收。隔离模拟及单开发机上的多个 Cell 不构成跨地域证据。真实接入需另立部署任务。

## 部署任务输入

- 服务负责人、审批人、供应商及两个实际地域和故障域；司法辖区、允许驻留的数据分类和模型清单。
- 各地域身份发行方、受众、服务主体、凭证引用和轮换负责人。工单只记录引用。
- 各地域存储、密钥、备份留存、复制方向、复制设施和单写权威切换方式。
- 公网或私网入口、受控出站目标、DNS/TLS、超时及故障探测方式。
- 按服务及数据集确定 RPO、RTO、计时边界、演练窗口和停止条件。目标值由负责人填写；未知保持空白。

## 接入前核验

1. 证明两个入口及状态存储分别位于所声明的实际故障域；核对供应商证明、有效期及证据责任人。
2. 验证服务身份最小权限、发行方和受众校验，并在隔离环境验证轮换和旧凭证退出。
3. 验证允许的数据驻留和跨域复制边界；以无敏感数据的标记核对复制水位、恢复读回和写权威隔离。
4. 验证生产适配器只访问登记端点；确认超时或失联时新任务停止放置，在途及不确定任务保持原身份和占用。
5. 检查回退路径和防重复执行措施，确认故障期间不会出现两个写权威。全部证据获批后才可开启真实放置。

## 恢复演练记录模板

- 演练编号、审批、环境、开始时间、版本与证据位置：
- 故障域、模拟故障、基线任务和持久水位：
- 停止新放置及确认旧写权威隔离的时间：
- 备用地域恢复已确认数据的时间和水位：
- 恢复外部服务并完成读写验证的时间：
- RPO 目标 / 实测；实测按最后一个确认写入与可恢复水位计算：
- RTO 目标 / 实测；实测按约定故障起点到服务验证完成计算：
- 原任务、租约、预算、账本与审计记录的对账结果：
- 回退执行记录、异常、负责人及复验日期：

任何目标、测量或证据缺失时不得标记真实接入就绪。
