## 服务与权限

新增 Gateway 接口：

| 接口 | 行为与权限 |
| --- | --- |
| GET/POST `/v1/admin/finops/rate-cards` | 全局 SRE 读取历史、CAS 创建不可变内部费率 |
| GET `/v1/admin/finops/rate-audit` | 全局 SRE 读取模板事务审计 |
| GET/PUT `/v1/admin/tenants/:id/rate-card` | 授权读取激活历史；SRE 显式激活目录版本 |
| GET `/v1/admin/tenants/:id/costs` | 授权账目分页与租户临时汇总 |
| GET `/v1/admin/finops/summary` | 按授权目录有界查询，缺失/不可达租户明确列出 |

身份来自现有 Gateway 验证，旧只读凭据不能写入。浏览器只提交版本号，不接受 actor、实际费率快照或成本中心版本。TenantDirectoryCell 唯一创建模板，租户服务使用目录凭据从私有绑定读取模板，并核验完整摘要。历史和账目游标使用 HMAC、调用者作用域和冻结上界，新增记录不改变已开始的分页。

## 执行与自动投影

Fleet 验证真实 Body 归属后，仅首次执行前 RUNNING 绑定有资格固定价格。租户服务读取真实目录归属/成本中心版本，价格 pin 与用量绑定加入同一原生同步事务；任何失败均整体回滚。未知池保持 null，池专属价格不能据此猜测生效。

晚到或已完成流、已有无价格预留、已有用量绑定均不补价。当前新执行可固定显式激活快照；旧准入预留保留其原来的 null。将来准入自动创建及成本上限仍需 QF-02 接线，不能用执行时价格替换已存在的预留快照。

签名用量接收与不可变账目投影同事务提交，回执重试不会重复累计；原始事件冲突仍持久隔离。读取成本时有界恢复最多 100 条尚未投影的已接收历史事件，保持原价格/无价格上下文。汇总上限、未投影和未知项均影响完整性，`totalCreditUnits=null` 与已知子总额分开，固定 `final=false`。跨租户读取并发 4，最多 1000 个授权租户；超限拒绝，超时或不可达的响应不计作零。
