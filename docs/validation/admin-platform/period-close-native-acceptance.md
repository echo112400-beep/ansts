# QF-05 鉴权关账与自动晚到调整

## 自动调整

认证后的录入路径把签名用量、成本投影和对应调整放在同一原生 SQLite 事务中。已关闭月份中的晚到用量关联原单摘要，进入下一个可用开放月份。重放保留同一调整和归属；写调整失败时，用量与成本投影一起回滚。关账后收到的冲突证据产生待核对记录，原关账单保持原文。

真实隔离 celld 接收了属于前一已关账月份的签名测试事件；重放和批量恢复扫描没有再次生成调整。关账和调整均进入备份 v2，重启后原文保持，并通过离线恢复。测试前一月的原关账由隔离夹具构造。

## 关账入口

POST /v1/admin/tenants/:tenantId/settlements/:periodId/close 需要对目标租户具备全区域权限的 SRE 管理身份、Idempotency-Key 请求头，以及 expectedRevision 和 reason 请求体字段。租户权威自行读取 Scheduler/Body 覆盖并校验预览版本。客户端覆盖字段被拒绝。同键同内容返回原收据，同键变更请求内容返回冲突。公共收据省略内部证据、流标识和冻结 basis。

隔离 celld 探针实测无身份、Viewer、跨租户和注入覆盖分别返回 401、403、404、422。缺历史时关账返回 409 PERIOD_INCOMPLETE，覆盖更新后使用旧版本返回 409 VERSION_CONFLICT。正向验收在空租户上用模拟的历史清单起点建立完整覆盖，并发提交返回同一份零金额关账收据，改用其他理由重放返回 IDEMPOTENCY_CONFLICT。

控制面 200 项、全仓类型检查、lint、构建和原生脚本均通过。本轮使用单个隔离 celld 实例，带真实取消、失败或 UNCERTAIN 执行的月末关账仍待验收。

## 独立 Gateway/Fleet 进程

运行 python3 scripts/verify_directory_gateways.py，退出码 0。两个 Gateway 容器通过 ANSTS_DIRECTORY_URL 向独立 Fleet 发出请求。历史不足时返回 PERIOD_INCOMPLETE；仅在隔离环境注入空月份的历史起点后，两个 Gateway 并发得到同一份关账收据，Fleet 重启后读回原收据。本轮未部署到开发环境。

## 真实执行失败与取消用量

原生脚本默认让真实 Docker Engine 容器退出 7，另用 ANSTS_EVIDENCE_TERMINAL=cancel 在 Body 已报告 RUNNING 后调用沙箱停止入口。两次运行均退出 0。Scheduler 分别收到 FAILED 和 CANCELLED，Body 提交认证的终止证据；Fleet 重启后两个场景均可读取资源分段和关闭事件。隔离执行在当前月且无价格快照，保持预留待核算；仍需验证这些终态在有价格和完整月度覆盖下的关账结果。

## UNCERTAIN 阻断

原生 celld 通过准入 API 创建预留并转为 UNCERTAIN。夹具只将创建时间移入测试月份，并为该空月份提供模拟清单起点。Gateway 预览显示覆盖完整，唯一阻断原因为 UNSETTLED_ADMISSION_RESERVATIONS；提交返回 409 PERIOD_INCOMPLETE。通过准入 API 取消这条从未授权启动的预留后，预览恢复完整，并发关账取得同一份收据。原生验收脚本退出 0。

### 带固定费率的终止执行入账

以 ANSTS_EVIDENCE_PRICE_TERMINAL=true 运行原生脚本，默认验证退出码 7，附加 ANSTS_EVIDENCE_TERMINAL=cancel 验证已启动后停止。两个场景均在启动前固定费率，使用实际终止证据和已闭合用量生成完整的成本预览，通过准入结算进入 SETTLED 并保存 UTC 日入账记录。Fleet 重启后逐字段核对预留结算记录。两次脚本均退出 0。该验收发生在开放月份，尚未验证这些执行进入非空月结关账单。

### 非空关账回放

两种带价原生探针均退出 0。隔离 SQLite 从 Fleet v2 归档提取真实失败或取消执行的原始用量、固定价格、成本投影和 SETTLED 预留，仅重排所选事件的本地序号。以模拟月末时钟和单次尝试覆盖调用关账内核，两种收据均有正金额、包含原始资源分段摘要，重放原样返回。在线单租户非空月份自动覆盖仍待部署验收。

## 人工补收与扣减

SRE 管理员在目标租户全区域授权下，通过 POST /v1/admin/tenants/:tenantId/settlements/:periodId/adjustments 提供非零有符号整数 creditUnits、原关账单摘要 expectedCloseDigest、reason 和 Idempotency-Key。调整关联原单并计入下一可用开放月份。采用有符号整额，允许目标月份净额为负。明细记录操作者、原因和请求，固定进月份版本与归档。

控制面 201 项、类型检查和 lint 通过。校验正负调整、原单版本冲突、授权与幂等、净额为负的目标关账及备份恢复。隔离 celld 实测并发提交只生成一笔扣减、预览反映扣减以及原单重放逐字段一致。脚本退出 0。

## 月中创建的任务与历史缺口

Scheduler 必须覆盖整月。对于月中创建的任务，如果 Scheduler 保留了未导入、零 fencing 的创建记录和一致的创建时间，并且 Body 留存从版本 1 的 ADMITTED 开始的连续链，则 Body 的清单只需从首次准入开始覆盖。只有租约记录、导入基线、超出首次准入的覆盖起点仍会阻止关账。测试通过真实 SQLite 清单的分页接口证明月中任务可以形成完整的非空覆盖，并验证提高导入水位会恢复历史缺口阻断。控制面 202 项、类型检查和 lint 通过。历史缺口仍需从权威证据恢复或保持待核算。

### 历史未计量任务处置

- 预览出现 HISTORICAL_COVERAGE_UNAVAILABLE 或 BODY_ATTEMPT_HISTORY_UNPROVEN 时，先保留来源归档，再从受信的 Scheduler/Body 备份恢复原有连续清单。迁移基线只能证明恢复时的状态，不能补齐此前的历史。
- 已发现执行尝试但缺用量时，核对 Body 原始签名 outbox。若原事件仍在，按原执行身份、fencing、事件 ID 和序号走已认证的用量重放路径。重放后重查预览，直至覆盖、事件序列及固定价格均完整。
- 无法恢复原证据或执行时价格的月份保持待核算，保留未结预留和未知总额。人工正负调整适用于已有的关账单，不能作为补齐覆盖、用量或价格的依据。恢复与否以预览诊断、原始证据水位和最终收据为准。

原生补验中，Gateway 预览和私有覆盖接口读取了真实 Scheduler 与 Body 清单。隔离夹具设置 Scheduler 的月初清单起点后，失败容器及成功 Agent 均出现在本月的尝试清单，覆盖只受当前月份尚未结束限制。原生脚本退出 0。此项未在月末时钟下在线提交非空关账。

### 历史窗口补录后经 Gateway 关账

控制面集成测试使用真实 Gateway 鉴权与租户 SQLite，Scheduler/Body 来自隔离 SQLite 清单。已结束月份的执行身份和价格固定，覆盖完整但用量事件尚未送达时，Gateway 返回 PERIOD_INCOMPLETE。重放原始签名事件后，旧预览版本返回 VERSION_CONFLICT，新预览与最终收据均为 1 个 credit 子单位。重建租户对象后同键重放返回原收据。控制面 203 项、全仓类型检查和 lint 通过。历史记录与月份均为测试夹具，未写入开发环境。

### QF-05 估算设计：2026 年 10 月基线加 10%

按用户指定，以 2026-10 UTC 月份为基线。对同一租户、同一成本范围的非负月度基线 B（整数 credit-subunit），设计月度额度 = ceil(B × 1.10)，以整数计算为 (11 × B + 9) 整除 10。只在汇总后向上取整一次。例如 B = 101 时，设计额度为 112。记录基线来源、租户范围、费率与归属口径，方便复核。

现有 10 月预览覆盖不完整且尝试为空，尚无可信的月度基线金额。按用户授权填写规划估算：范围为开发租户 m3-pilot。沿用已演练的每 UTC 日 10 credit-subunit 额度，假设 10 月 31 天均按日额度计入规划基数，得到 310 credit-subunit。上浮 10% 增加 31，设计月度额度为 341 credit-subunit。基数为额度推算，10 月实际费用仍待核算。上浮值仅用于设计和预算预估，正式关账保留连续执行清单、原始签名用量与执行时费率的校验。
